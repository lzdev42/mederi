Core Capabilities

它能替你完成什么工作？

脱离纯聊天的限制，赋予 AI 真实调用工具、操控系统与落地的能力。

自主编程与重构

自主分析项目代码库，制定多步骤修改计划。直接读写文件、通过内置终端执行编译与单元测试，根据报错日志自我纠错。

• 真实文件读写 • 内置 PTY 测试执行

自动化网页与浏览器操作

通过 Playwright 驱动真实无头或有头浏览器。能替你自动登录系统、填写表单、查询网页数据并对复杂页面进行结构化信息提取。

• Playwright MCP • 网页自动化抓取

日常工作与复杂工作流

面对含糊多步骤的日常任务，先理清方案生成清晰的步骤清单（Plan），经你确认后再有序执行，避免传统 AI 乱跑乱改。

• 计划驱动状态机 • 本地状态随时恢复

Architecture & Harness

真正的 Agent Harness 架构

Core 与 UI 彻底解耦，兼顾单机极速体验与服务端集群调用。

Mode 01: Desktop 单机运行 本地内嵌

Harness Core 直接内嵌在 Compose 桌面客户端进程中，单机零配置秒级启动。适合个人日常辅助编程、网页自动化与文件处理。

./gradlew :app:desktopApp:run
Mode 02: Headless 服务端部署 守护进程

以独立 Server 进程常驻在服务器或本地后台，暴露标准 REST & SSE 协议，自托管 Web UI，外部脚本与 CI/CD 流程可直接调度。

./gradlew :server:run (Port: 8081)
PRESENTATION Compose Multiplatform (Desktop) & wasmJs (Web)
Skiko Native Canvas · No CEF Overhead
↓ Remote Contract / In-Process Bridge (Ktor SSE & StateFlow)
HARNESS CORE Mederi Core (PlanStore, SessionStore, ProviderStore)
Triage FSM · SQLite · JetBrains Koog Engine
↓ Execution Dispatcher & Kernel Hooks
