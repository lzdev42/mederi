# Mederi UI 重构规范文档

本文档明确了 Mederi 桌面与跨平台端 UI 视觉与架构交互统一规范：

  • 对话流：工作过程统一聚合进 WorkTraceCard，支持限高独立滚动与全量展开；
  • 右侧栏：原 DIFF 升级为文件面板，双 Tab 涵盖项目目录树与改动文件；原 ARTIFACTS 升级为文件阅读面板，支持任意文件点开即读。

实施计划：重构侧边栏与工作流 (plan_c8f31b)

状态： PENDING_APPROVAL (待批准)

技术方案： 按照 Mederi 架构对齐三大菜单与 Footer；在对话流聚合工作过程；在右侧栏将 DIFF 升级为文件面板，提供项目目录与改动对比双视角，同时提供统一文件阅读器。
