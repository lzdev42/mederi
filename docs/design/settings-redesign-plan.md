# 设置页改造计划

> 2026-10-29：用户授权把设置页纳入整体UI改造。当前S1–S3、S5及公共弹窗/自有动效已完成代码与组件验证，S4浏览器由用户取消；S6整体清理和完整APP/三平台验收仍待完成。各批证据见下表。
> 总入口：[工作台总计划](conversation-workspace-redesign-plan.md)。设计真理源仍是`standard/`，本文件只记录设置范围、顺序与验收，不建立第二套风格。

## 1. 目标与不变量

设置页延续中性、轻量、内容优先的跨平台工作台风格。降低容器、装饰图标和重复标题的存在感，让用户看清“改什么、当前值是什么、是否生效、失败怎么处理”。尊重各平台窗口外壳，内容不模仿某一系统的专属材质、交通灯或控件。

现有功能、可选值、保存时机、权限与宿主能力保持。UI迁移不新增Core行为，不改配置路径、存储schema、自动保存/显式提交语义，也不顺便删掉高级选项。加载/错误/不支持使用真实状态，未加载数据不伪装成成功或有效默认值。发现已有行为问题独立登记，不混进视觉改造。

**同类语义必须真实共用View**：确认统一ConfirmDialog，编辑统一InputDialog或MederiDialog内共同表单，错误简报/详情复用既有错误组件族，菜单/提示/按钮/空态也共用。设置需要busy、disabled、可选详情/重试时扩展共享接口，不复制近似实现。领域专属的ProviderKeyDialog等保留为组装层，不能自绘另一套确认壳与动作。只共享表现，不合并领域数据或业务可用性。

## 3. 一致的布局与视觉规格

- 桌面左导航目标宽约176–200dp；右侧内容限制阅读宽约720–800dp，供应商允许更宽的主从工作区。实际断点由“导航+内容最小可用宽”决定，不能照抄旧760dp后挤成窄列。
- 窄屏保留横向分类（共用数据与选中语义），内容单列；供应商列表/详情采用前进/返回，字段草稿与真实选择不能被无关重组清空。
- 标题只在页面出现一处；页标题约16sp Medium，组标题沿用Title13/20，正文Body13/20，辅助Caption12/18；不为设置另创一套字号。路径/JSON等内容按需等宽。
- 普通设置用留白、对齐与少量发丝线分组；不为每个开关套完整卡片。取消常规图标的彩色托盘，必要图标16dp、语义颜色按状态使用。
- 字段标签在上、帮助在下；宽屏“左说明右操作”，空间不足自然上下排。正文可换行，操作最小30dp、不被长标题挤走；触控沿平台热区要求增加实际可点击区。
- 按钮、菜单、Tooltip、Dialog沿用现有共同实现；hover/focus120ms、展开180ms，最终消费同一MotionPolicy。不会新建SettingsV2控件或临时平行设计系统。
- 错误就近显示并使用共同错误View，不能只日志；有真实诊断时才给详情，有真实恢复能力才给重试。保存反馈只展示真实结果；不能新增一套虚假的“已保存”本地状态。

## 4. MVVM与状态边界

沿用MVVM＋单向数据流，无全局MVI框架重写。

- Route负责取得现有AppState/Store/VM、生命周期绑定与一次性效果；Content只收不可变展示值与回调。ProviderSettingsViewModel/Browser store及现有AppState仍是真理源，不建统一SettingsStore复制全配置。
- View只保留展开、当前呈现分类、显隐密码等纯表现状态。表单草稿沿用原提交边界；不能在每次状态回流时覆盖用户输入或重置光标。
- Agent面板等直接在Composable中读取/更新AiCore的路径逐页迁入表现协调层，先建立现行为回归再迁移；保持同一API和原能力，未迁移部分明确记录，不能仅改函数名就宣称MVVM完成。
- 设备偏好（主题/语言/动效）继续设备本地，服务端配置仍走原AiCore契约；错误/保存/安装/启停属于已有状态，不塞到通用View。无业务改动时不改AiCore四处契约。

## 6. 验证与维护要求

- 测试重点是原功能契约：选择传什么值、提交给谁、禁用条件、何时保存、失败怎么呈现；视觉预览使用实际Content组件，不用另一份画出来的假页面替代。
- 按页新增有意义的Compose交互测试，优先用fake回调/Store避免改真实供应商、启动遥控或下载安装浏览器。供应商既有ProviderSettingsFreeFilterTest、推理ReasoningMenuTest以及公共弹层WorkspaceSixthDeliveryTest继续回归。
- 实施后至少`:app:shared:compileKotlinWasmJs`与本批实际新增的jvmTest suite通过；完整APP/server只通过idea-mcp，不用bash硬跑。没有环境就写未验证。
- 代表状态：加载/空/错误/进行中/不支持、长路径/多供应商/多Key、多语言、深浅、窄宽与125/150/200%字体；不要求每页复制同一套测试，但公共原子与每页独有功能必须覆盖。
- 改签名/状态结构同步`docs/architecture/02-app-shared.md`，改变读取/保存/效果路径同步`04-flows.md`；共享规格同步`standard/`。当前仅规划，不报告编译/视觉已通过。
